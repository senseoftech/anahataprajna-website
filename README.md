# Anahata Prajñā — site web

Page d'attente du site Anahata Prajñā, hébergée sur GitHub Pages.

- `index.html` — page d'attente (HTML/CSS statique, sans build)
- `assets/logo.png` — logo

## Déploiement

Le site est servi par GitHub Pages depuis la branche `main` (racine).
Pour le domaine personnalisé, ajouter un fichier `CNAME` à la racine contenant le nom de domaine, et configurer le DNS chez le registrar.
