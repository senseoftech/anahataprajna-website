# Anahata Prajñā — site web

Site d'Anahata Prajñā, chant d'ancrage et chant vibratoire, par Mélissa Letenre : <https://anahataprajna.be/>.
Hébergé sur GitHub Pages, servi depuis la branche `main` (racine). Le domaine est déclaré dans `CNAME`.

## Contenu du dépôt

Le dépôt contient le site tel qu'il est publié : des pages HTML statiques, sans étape de build côté serveur.

- `index.html`, `essence.html`, `chant-ancrage.html`, `chant-vibratoire.html`, `vivant.html`, `contact.html` — les six pages
- `404.html` — page d'erreur
- `css/base.css` (structure) et `css/skin.css` (couleurs, polices, formes)
- `js/frequences.js` — figures de sable, ondes, curseur de fréquences et bol chantant, formulaire de demande
- `assets/` — logo, icônes, image de partage, photos
- `robots.txt`, `sitemap.xml`, `llms.txt`, `llms-full.txt`, `site.webmanifest` — fichiers pour les moteurs de recherche et les assistants IA

## Mise à jour

Les pages sont produites par un générateur conservé hors de ce dépôt. Ne pas les modifier à la main :
toute modification directe serait écrasée à la génération suivante.
